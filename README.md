# Lotto 6/45 V3.7 — 全模型联合优化平台（离线手动数据）

V3.7 将参数实验升级为一次性全模型联合搜索：7种可调模型共搜索500组唯一参数配置；均匀随机基准作为所有内层、外层和最终保留测试中的配对控制模型。系统使用嵌套滚动验证、独立保留测试集和 Pareto 多目标分析。

## 固定数据政策

- **禁止连接韩国 Lotto / 동행복권 官方网站及其 API。**
- 禁止自动爬取、定时同步或通过后台任务获取开奖数据。
- 仅分析用户手动导入的 CSV、XLSX、XLS，或仓库 `data/lotto645.csv` 中由用户手动维护的数据。
- 不要把回测明细 CSV 当成开奖历史数据。

## V3.7 联合优化规格

| 项目 | 正式配置 |
|---|---:|
| 模型范围 | 全部8种（7种可调策略 + 均匀随机基准） |
| 唯一参数配置预算 | 500组 |
| 可调模型分配 | 每个模型71或72组，尽量均衡 |
| 每期每个模型/配置 | 10注 |
| 随机种子组 | 3组 |
| 优化目标 | balanced |
| 最低训练历史 | 300期 |
| 外层嵌套滚动验证 | 2折，每折30期 |
| 内层参数验证 | 每个外层训练前缀2折，每折5期 |
| 独立保留测试集 | 最新100期 |

均匀随机基准不属于可调参数候选，因此不消耗500组预算；但它会在每个目标期、每个随机种子组中作为共同随机对照，参与所有候选配置的配对比较。

### 500组参数搜索覆盖

1. 近期频率：窗口和近期先验强度。
2. 长期频率：长期平滑先验强度。
3. 指数时间衰减：半衰期。
4. 贝叶斯平滑：先验强度。
5. 综合评分：短、中、长期融合权重及窗口。
6. 历史结构约束：和值分位数边界。
7. 多模型集成：近期、贝叶斯、衰减三类权重，以及对应参数。

### 嵌套滚动验证与独立保留集

- 每个外层测试折只使用其测试块之前的历史数据开展内层参数搜索。
- 每个内层目标期的模型特征只从该目标期之前的历史记录计算。
- 500组唯一配置在不同外层折间复用；不会为每一折重新增加预算。
- 外层折用于评估“搜索并选出参数”这一完整流程的样本外表现。
- 全部开发数据用于最终一次参数选择，随后只对一个冻结的 balanced Pareto 配置评估最新100期保留集。
- 保留集评估后即视为已使用。不要根据该结果反复改参，再声称该区间仍是独立测试集。

### balanced 与 Pareto 定义

六个目标等权使用百分位排名：

- 相对随机的平均命中差（最大化）
- 相对随机的单注3+率差（最大化）
- 相对随机的整批至少一注3+差（最大化）
- 相对随机的号码覆盖差（最大化）
- 相对随机的平均组间重号减少（最大化）
- 内层折间平均命中差稳定性（以负标准差表示，最大化）

`balanced_score` 是候选配置在上述六项目标上的平均百分位排名，只是多目标选择启发式，不是概率、p值或显著性分数。Pareto 前沿保留不存在被其他配置在全部目标上同时支配的方案。随机基准也作为一个零差异参考点显示，但不作为可调候选。

## 部署（GitHub 网页，无需本地安装 Python）

1. 先下载当前 GitHub 仓库 ZIP 备份。
2. 在 GitHub Actions 中禁用旧的自动同步工作流，并删除会触发外部开奖数据读取的旧 workflow YAML。确认仓库中没有定时抓取任务。
3. 解压 V3.7 升级包。
4. 在仓库根目录替换：`app.py`、`lotto_core.py`、`backtest_engine.py`、`model_registry.py`、`data_manager.py`、`sync_data.py`、`requirements.txt`、`README.md`。
5. 在仓库根目录新增：`joint_optimizer.py`。
6. 保留 V3.6.1 的其他模块：`parameter_optimizer.py`、`portfolio_optimizer.py`、`model_management.py`、`experiment_export.py`。本包也包含这些文件，可一并覆盖到对应位置。
7. 上传 `tests/` 文件夹（推荐）。
8. **保留仓库现有 `data/lotto645.csv` 和 `data/sync_status.json`（如有），不要用 baseline 文件替换。**
9. 只将本包中的指定根目录代码文件放入仓库；不要覆盖原始 `data/`。不要重新启用旧自动同步 workflow。
10. Commit 到 `main`，等待 Streamlit Cloud 自动重新部署。

## 统计解释边界

公平且独立开奖下，每一注固定六号码组合的理论头奖概率相同，为 1 / 8,145,060。模型评分、参数排名、Pareto 前沿、历史回测领先和组合覆盖率都不等于未来预测优势。独立保留集用于检验已冻结的单一配置，不能反复用于选参。
