# V8.8 — Multiple random portfolio control

## Research question
Does V5, V8.1 or V8.5 outperform a well-estimated uniform-random ten-ticket portfolio distribution, rather than one arbitrary random control portfolio?

## Design
- Reuse the strictly prequential V8.5 replay to generate V5, V8.1 and V8.5 tickets without target-draw leakage.
- For every target draw, generate 1,000 independent uniform random portfolios, each containing ten distinct six-number tickets.
- Sample each ticket uniformly from all six-of-45 combinations; reject duplicate tickets within the same ten-ticket portfolio.
- Compare each model's batch 3+ result with the per-draw random distribution and expectation.
- Report per-draw random mean, standard deviation, 2.5/97.5 percentiles, 95th percentile and model empirical percentile/exceedance rate.
- Primary inference uses paired per-draw differences from the Monte Carlo random expectation, moving-block bootstrap over target draws (10-draw blocks, 10,000 repetitions), and Holm correction across three primary comparisons.
- Secondary metrics (batch 4+, mean hits, ticket 3+/4+, best hits) are descriptive.

## Statistical safeguards
The 1,000 random portfolios per draw are Monte Carlo replicates used to estimate that draw's random-null distribution. They are not 1,000 independent lottery draws and do not inflate the inferential sample size. The target draw remains the statistical unit. The historical 752–1251 window has already been examined in earlier research, so the result is retrospective prequential evidence, not an untouched holdout or prospective validation.

## Boundaries
Research only. No production picker changes, no forward-lock writes, no edits to existing commitments, no Streamlit changes, and no access to the official lottery website or API. Historical data is read only from the manually supplied CSV.
