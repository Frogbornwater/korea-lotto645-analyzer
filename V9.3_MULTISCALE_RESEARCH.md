# V9.3 — Multi-timescale prequential research

Research-only comparison of fixed historical windows 20, 30, 50, 100, 200, 300, 500, 800 and 1000 draws, plus a predeclared equal-weight ensemble.

## Protocol
- Frozen input is the manually maintained `data/lotto645.csv`; no official lottery site/API access.
- Targets start after 1000 historical draws, so every model is scored on the exact same target cohort.
- At target draw t, forecasts use only draws strictly before t.
- Each window uses a fixed Dirichlet-style shrinkage strength alpha=80 toward the uniform marginal inclusion probability 6/45.
- Primary endpoint: mean per-draw Brier score over all 45 inclusion indicators.
- Secondary endpoints: mean Bernoulli log loss and Top-6 hit count.
- Comparisons are paired against the uniform marginal forecast; block-10 moving-block bootstrap CIs preserve short-range temporal dependence. One-sided block sign-flip tests apply a shared random sign within each contiguous block rather than independently flipping each draw.
- Holm correction covers the nine fixed windows and equal-weight multiscale ensemble for the primary Brier tests.

## Decision rule
No winner is selected from this same evaluation set and no model is promoted. A candidate requires adjusted statistical evidence, confidence intervals in the favorable direction, chronological subperiod stability, and independent prospective confirmation. A historical frequency association is not assumed to imply future predictive power.

## Scope
Adds a research module, tests, workflow and artifact report only. Does not change the production picker, Streamlit UI, historical CSV, forward locks, or any official-site/API integration.
